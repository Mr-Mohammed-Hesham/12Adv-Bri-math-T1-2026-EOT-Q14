Inverse Function Derivative: g'(a) = 1/f'(g(a))

g'(a) = 1/f'(g(a))
Inverse Function Theorem
If f(b) = a, then g(a) = b
Find b first!
g'(a) = 1/f'(b)
Where f(b) = a
f · g = g · f = identity
f(g(x)) = x
f'(x) ≠ 0 required
For inverse to exist
g = f⁻¹
Inverse notation
